## Pretext — what it is and how we used it

`@chenglou/pretext` (v0.0.8) is a client-only text measurement and layout engine. `prepare()` / `prepareWithSegments()` uses canvas measureText (never during SSR). `layout()` / `layoutWithLines(handle, width, lineHeight)` is pure arithmetic and is what we rerun on resize.

Files:

- `lib/pretext.ts` — wraps prepareWithSegments + layoutWithLines. If the package throws, a tiny Offscreen/canvas measureText fallback still ships (CJK via Intl.Segmenter graphemes). The installed package is the primary path.
- `app/components/PretextLines.tsx` — client hook: prepare once per text+font, ResizeObserver relayout, per-line reveal. Locale is passed for zh-Hans / zh-Hant / ja / ko / th. prefers-reduced-motion skips the reveal.

Used for:

1. Hero line + tacit line on home (editorial per-line reveal / reflow as the column width changes).
2. Writing tacit line; PostCard excerpts (tight = chat-bubble tightness, width fit-content).
3. Product notes on /products.
4. Product intro titles / one-liners / lower-thirds (measured lines, minHeight from layout so the reel does not jump).

We did not call prepare() on the server.
